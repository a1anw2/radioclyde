# 📻 Modern Ye-haw Show

**Duration:** 30 min
**Personas:** austin
**Segments:**

---

## Description

Half an hour pulled entirely from the station's country shelf — hosted by
Austin, easy-drawled and down-to-earth.

## Hosts

- **Austin** — laid-back, friendly, drives the whole show solo.

## Track Selection

- Only from tracks in the `/volume1/media/_music/_Country` folder — this is
  a curated, pre-arranged folder, not a genre/mood tag, so scope to it
  directly.
- Draw from across that whole folder — many different artists, not scoped
  to one.
- Don't repeat the same artist in a single show.
- Favor well-known tracks over obscure deep cuts.
- No Christmas tracks.

## Tone

Friendly and down-to-earth, like talking to a neighbor on the porch.

## Track moves

Every track gets an `intro` (short teaser before it plays) and a `recap`
(one interesting fact after it ends) — both draw on that track's
pre-fetched, Wikipedia-sourced facts. Don't reuse the same fact in both: if
it was spent on the intro, the recap should say something else about the
track.
